# DODGE GUY
## Project 
### Tech Stack 
The game was made in Godot. Yes even the AI i will explain how.

### How
To make the AI in godot. I needed to create the neural network from scratch . The class NeuralBrain has copy(), mutate(), and compute() functions, you may copy the file Neural_netwok_class.gd and use it in your projects.

### Make your own
I know the art is bad, thus to improve it or train my AI even more you can follow the steps:
- Copy repository
- Import project in godot
- Click project.godot
- GO

### Train
You may use the train () function in level to train my AI.
 
## Game

### Instructions 

Use WAD to Move.
Outlast my AI in a world moving left and WIN.
Remember you must outlast him not go ahead, play carefully though its dumb.

[PLAY HERE](https://salprokite.itch.io/dodge-guy)

### Art and Difficulty
I have been busy and making the AI itself and then the world was a big hassle. My original plan was for a much larger and polished game with many more features. But due to time constraints I could make a very small game.                                                                                                                                                                   
Thus forgive me for no art and dumb AI and possibly wacky controls. The core AI remains functional and that was the hardest part, in a future update I will for sure greatly improve this game and stay tuned to see it happened. Right now the demo is the reflection that I made an agent nothing else.
This project would be much more programming and logic than game dev and I forgot to account for that leading to poor decisions so consider this a display of code and not of game dev.
